# Snake Game 

Классическая игра «Змейка», реализованная на Python с использованием библиотеки Pygame.

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите игру: `python main.py`

## Управление
- Стрелки на клавиатуре (вверх, вниз, влево, вправо).

## Правила
- Съешьте яблоко, чтобы вырасти.
- Змейка проходит сквозь стены.
- При столкновении с собой игра перезапускается.
